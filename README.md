# SLAVA / Resonance in your hands

SLAVA 的高端品牌電商官網重建版。這個版本以黑色劇院感、木材與黃銅的材質語彙、液態玻璃輔助介面，以及可拖曳旋轉的產品展示為核心。

## 本機預覽

在專案資料夾執行：

```powershell
python -m http.server 4173
```

再開啟 <http://127.0.0.1:4173/>。

## 已完成

- 置入品牌提供的正式 `assets/brand/slava-logo.svg`。
- 使用 Typekit `https://use.typekit.net/gbe4lzj.css` 的 `pirulen` 作為英文介面字型；中文使用黑體字型系統。
- 首頁高端暗色舞台、環境星塵、材質光暈與液態玻璃導覽。
- LONG / ROUND 產品切換，可拖曳或滑動旋轉 3D 展示；若瀏覽器無法載入 WebGL / CDN，會自動使用產品去背圖備援。
- 以目前產品照片生成的兩張透明背景展示資產：`slava-long-cutout.png`、`slava-round-cutout.png`。
- 購物袋、數量調整、產品價格、會員登入／建立帳戶視窗、訂單意願表單。
- Web Audio 空間聲音開關與音量感測器視覺；聲音只會在使用者點擊後啟動。
- 產品、材質、FAQ、購買入口與行動版響應式版面。

## 上線前仍需串接

目前會員、購物袋與訂單是可操作的前端體驗層，沒有假裝已經接上真實金流或資料庫。正式開站前建議接上：

1. Supabase / Neon：會員、訂單、候補名單與後台資料。
2. 綠界、藍新或 Stripe：付款、退款與訂單狀態。
3. Resend / MailerLite：下單通知與候補名單。
4. 正式隱私權政策、退換貨規則、保固與產品責任文字。

## 資金與成本模型

募資前的啟動現金、單位經濟與三種情境比較，整理在 [SLAVA_budget_model.xlsx](outputs/01a11e92-a77a-7a32-84c4-2a79ea019f63/SLAVA_budget_model.xlsx)。黃色欄位是需要替換成正式報價的初始示例值。

建議執行順序：先完成 10–30 件小批量試作與聲學測試，再整理 BOM、報價單、試作照片、品牌簡報與預購頁，接著依所在地與公司資格申請青年創業、地方創生、文創／設計研發或創新研發類補助。補助名稱、資格與期程需要依申請地區和年度公告逐案確認，不能直接把網站上的預估金額當成核定額度。

## 部署

這是一個純前端靜態專案，根目錄可直接部署到 Vercel。`vercel.json` 已加入基本安全標頭與靜態素材快取設定；`.gitignore` 已排除 Vercel 暫存資料、依賴與舊的工作產物。
