SLAVA / PATENT APPLICATION MAP

先保護核心，
再放大產品。

這份流程以台灣專利申請為基準，把 SLAVA 的結構、材質組合、安裝方式與外觀設計拆成可以執行的保護路線。

FOR SLAVA 先做保密與檢索，再決定申請組合。

你已有預售與產品曝光紀錄，請保留首次公開、展示、預售與測試日期；是否影響新穎性及是否適用優惠期，交由專利師依個案判斷。

01 / PROTECT結構與機能

木材、黃銅、碳纖維與組裝關係的技術特徵。

02 / DIFFERENTIATE外觀與比例

LONG、ROUND、表面輪廓與視覺辨識度。

03 / DOCUMENT證據與版本

STEP、GLB、照片、測試數據與每次改版紀錄。

01 / CHOOSE THE RIGHT RIGHT

同一個產品，
可以有不同保護層。

不是三選一，而是先釐清你要保護的是技術、外觀，還是品牌識別。

UTILITY MODEL

新型專利

適合先聚焦在物品的形狀、構造或組合。程序相對直接，但權利行使前要重視新型專利技術報告。

SLAVA 可評估：安裝結構、材料組合、可拆換或固定機構。
INVENTION

發明專利

適合具有技術效果、材料機制或方法創新的核心。需提出實體審查申請，審查深度與時間較高。

SLAVA 可評估：聲學改善機制、材料配置與可驗證的技術效果。
DESIGN

設計專利

保護產品外觀設計。要把視圖、比例、輪廓與設計特徵整理清楚，避免只交一張模糊照片。

SLAVA 可評估：LONG、ROUND、表面造型與系列外觀。
02 / THE APPLICATION FLOW

從保密到領證，
每一步都留下證據。

先完成能控制的工作，再把需要專業判斷的部分交給專利師。

01
CONFIDENTIALITY

盤點公開狀態與保密

整理預售、展覽、社群、網站、寄樣與測試的日期及對象。申請前避免再公開未保護的細節，並先簽保密協議。

輸出：公開時間軸／版本清單／保密名單
02
SEARCH

做先前技術與外觀檢索

用智慧局專利檢索與全球資料庫，找相近的結構、聲學附件、材料組合與外觀，建立差異表。

輸出：關鍵字／分類號／相近案件／差異特徵
03
SCOPE

決定申請組合與權利範圍

依檢索結果決定新型、發明、設計是否分案或並行；把真正有價值的技術特徵寫成請求項方向。

輸出：申請策略／主張特徵／是否委任專利師
04
DRAFT

準備文件與圖式

發明／新型通常包含申請書、說明書、申請專利範圍、摘要及必要圖式；設計則以說明書與圖式為核心。

輸出：說明書／請求項／摘要／工程圖／外觀視圖
05
FILE

送件、繳費並取得申請日

可依智慧局電子申請與紙本程序辦理。必要文件齊備的日期會影響申請日與後續判斷，送件後要保存收據與案號。

輸出：申請案號／繳費證明／送件版本封存
06
EXAMINATION

依類型進入不同審查

發明：申請後 3 年內提出實體審查；申請案原則上自申請日起 18 個月後公開。新型以形式審查為主；設計依其審查流程辦理。

輸出：審查通知／補正或申復文件／技術報告（如需要）
07
GRANT

核准、繳證書費與年費

核准後依通知期限繳納證書費及專利年費，完成公告與領證；之後按期維護年費，並管理讓與、授權與版本。

輸出：專利證書／年費提醒／授權與商品化紀錄
08
IF REJECTED

被核駁時的救濟路徑

依案件類型與審定內容，評估補正、申復、再審查或行政救濟；時限以個案送達日及官方通知為準。

輸出：專業意見／修正版請求項／下一步決策
03 / SLAVA PREP LIST

現在就能整理的
專利資料包。

讓專利師或申請人第一次看資料時，就能快速理解產品的技術核心。

01產品與工程資料

STEP、GLB、爆炸圖、尺寸、材料表、組裝順序與不同版本差異。

02效果與測試資料

大提琴安裝位置、對照組、錄音、頻譜、主觀評分與未來實測計畫。

03創作與公開證據

照片原檔、預售紀錄、社群貼文、展示日期、寄樣紀錄與保密協議。

04品牌與外觀資料

LOGO、LONG／ROUND 視圖、正側俯視圖、外觀變體與商品識別說明。

SLAVA 建議順序

先做一次先前技術檢索與公開時間軸，再決定「新型／發明／設計」的申請組合；若產品已經公開，先帶齊證據諮詢專利師，不要只用網路模板直接送件。
