# SLAVA temporary website demo

這是 SLAVA 的第一版品牌官網原型，已套用目前提供的 7 張產品照片。

## 本機預覽

在專案資料夾執行：

```powershell
python -m http.server 4173
```

再開啟：<http://127.0.0.1:4173/>

也可以直接雙擊 `index.html` 查看靜態頁面；若要確認圖片、錨點與互動，建議使用上面的本機伺服器方式。

Logo 方向預覽：開啟 `logo-preview.html`。

## 已完成的 demo 互動

- `LONG / ROUND` 產品切換：同步替換主圖、細節圖、文案與材質欄位。
- 產品圖庫放大預覽：支援關閉按鈕、點擊背景關閉與 `Escape` 關閉。
- 候補名單表單：目前只做前端成功回饋，尚未串接真實 Email 服務。
- Logo 方向預覽：A／B／C 三個暫定方向，供設計師與商標代理人討論。
- 滾動淡入、sticky 導覽列、FAQ 展開、`prefers-reduced-motion`。

## 下一版需要補的素材

- 安裝在大提琴上的實拍照。
- 兩款產品的正式名稱、尺寸、重量、適配琴型與安裝方式。
- 前後音色測試：固定琴、弓、麥克風、距離、空間與後製條件。
- Logo 向量檔、正式商標檢索結果、包裝與保固資訊。
- Email 名單服務與正式隱私權政策。
