01 / THE ROUTE

從產品證據
走到補助核銷。

先分清楚「已有的產品資產」與「本次要申請的新增工作」，再進入正式提案。

01
DEFINE

定義產品與資格

整理公司／商業登記、產品現況、創新問題，以及申請主體是否符合計畫條件。

  • STEP 3D 建模檔
  • 產品照片與 LOGO
  • 既有預售與使用回饋
02
MATCH

選擇資金管道

依研發內容、所在地與申請資格分流，不把貸款誤當成補助。

  • 中央 SBIR：研發與驗證
  • 地方型／青年創業方案
  • 貸款／信保：資金配套
03
WRITE

準備計畫書

把「材料如何影響大提琴練習」寫成可量化的研究方法與成果。

  • 琴上 A/B 對照測試
  • 頻譜、聲壓與演奏者回饋
  • 時程、報價與成果指標
04
SUBMIT

送件與審查

透過官方系統送件，保留申請版本與編號，依限期完成補件。

  • 資格文件
  • 計畫書與預算表
  • 報價、時程與自籌說明
05
EXECUTE

核定後執行

只依核定內容執行，並將本案支出、付款與驗收證明分開留存。

  • 進度與成果報告
  • 發票與付款紀錄
  • 避免重複申請／核銷
06
SCALE

核銷與商品化

完成成果驗證後，銜接量產、品牌、通路與下一階段資金。

  • 更新聲學測試數據
  • 改善設計與材料規格
  • 建立商品化版本
02 / BUDGET LOGIC

補助預算
怎麼算才乾淨。

「送件時可以列預算」與「既有成本可以追溯」是兩件不同的事。

＋
IN THIS APPLICATION

可列入本次申請

只要是本次計畫新增、必要且符合該補助公告的支出，就可以在提交資料時編列預算。

  • 大提琴琴上測試與委託測試
  • 新增材料試製、樣品與打樣
  • 模型優化、設計驗證與測試設備
  • 量產前改善、成果文件與必要顧問費
實際可編列項目仍以計畫申請須知與核定內容為準。
－
OUTSIDE THIS APPLICATION

先排除既有成本

不要把產品已經發生的成本，重新包裝成這次補助案的支出。

  • 既有啟動資金
  • 已完成產品的歷史成本
  • 已售／已預售商品的成本
  • 與本案無關的日常營運支出
既有預售不浪費：它可以放在市場驗證、需求證據與商業進度中。
SLAVA RULE可以編列「未來要做的事」，不能追溯列入「過去已發生的事」。

同一筆支出也不要同時向不同政府計畫重複申請或核銷。
